# 消火器よみ（shokaki-yomi）

火事の場面（紙・木材などの普通火災、灯油・天ぷら油などの油火災、電気設備の電気火災）と、消火器の表示（「普通火災用」「油火災用」「電気火災用」と絵表示）を見て、使える消火器を当てる1日5問の学習ゲーム。正解したら、その火事が普通火災・油火災・電気火災のどれかも選ぶ。絵表示の色・消火器の使い方の順番・使うときの注意の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/shokaki-yomi/>

- 中身は「消火器の技術上の規格を定める省令」（e-Gov法令検索 <https://laws.e-gov.go.jp/law/339M50000008027>）・消防法 別表第一と、総務省消防庁「消火器の正しい使い方」（<https://www.fdma.go.jp/mission/prevention/suisin/post2.html>）・東京消防庁・京都市消防局・横浜市・豊中市消防局の資料に書いてあることだけです。
- 絵表示はこのゲームで描いたもので、実在の消火器のラベルではありません。色だけでなく、形と「普通火災用」などの文字でも分けます。
- 問題に出る火事の場面は練習のための例で、本物の火事ではありません。
- このゲームは防災の助言や、公式の情報の代わりではありません。消火器の使い方は、消防の資料と、置いてある消火器の表示・説明書で確かめてください。
